# Jam Out! 卡住啦！

療癒系 3D 辦公桌益智遊戲，使用 Godot 4.7.2。版本：1.0.0-rc.1。

## 立即遊玩

**https://colin0801.github.io/JamOut/**

不用安裝 Godot。點擊小物，沿箭頭方向離場；先移開障礙，把桌面清空。支援關卡旅程、無盡整理、3 分鐘衝刺、每日挑戰，包含 11 種物件、連擊、兩套主題和本機紀錄。

首次載入需要下載約 49 MB 的遊戲檔案。建議使用支援 WebGL 2 的現代瀏覽器。遊戲進度保存在各自瀏覽器中，清除網站資料會清除進度。

## 網站更新

此倉庫儲存可直接部署的 Web 匯出檔。GitHub Pages 使用 main 分支根目錄；更新時請將 Godot Web 匯出的 index.html、index.js、index.wasm、index.pck、音訊 worklet 與圖片一起替換，再提交推送。不要只上傳 ZIP，也不要只更新其中一個遊戲檔案。

保留 `.nojekyll` 以直接發布靜態檔案。部署狀態可在此倉庫的 Actions 或 Settings → Pages 查看。
